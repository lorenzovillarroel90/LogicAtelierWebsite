Privacidad de Gem Bastion TD

Cómo gestiona Gem Bastion TD los datos de juego, las propinas opcionales y las solicitudes de asistencia.

Recogida de datos Qué guarda la app Propinas opcionales Este sitio web Ayuda y soporte Políticas relacionadas

Recogida de datos

Gem Bastion TD no recoge datos personales ni realiza seguimiento. La aplicación no tiene cuentas, publicidad ni herramientas de análisis.

Qué guarda la app

La aplicación guarda tu expedición y tus ajustes en el dispositivo. Al borrar la aplicación eliminas esos datos locales del dispositivo. Puedes gestionar las copias de seguridad en los ajustes del dispositivo y de tu cuenta de Apple.

Propinas opcionales

Si decides dar una propina, Apple procesa la compra. La aplicación usa StoreKit de Apple para confirmar la transacción y no recibe los datos de tu tarjeta. Apple gestiona el historial de compras y las solicitudes de reembolso.

Este sitio web

Este sitio web estático no tiene cuentas, formularios, cookies, analítica, publicidad ni scripts de seguimiento de terceros. GitHub Pages puede recibir registros ordinarios de solicitudes según sus propias políticas. El sitio no usa esos registros para identificarte ni crear un perfil.

Ayuda y soporte

Puedes contactar con el desarrollador mediante el enlace de la página de asistencia. GitHub trata la información que decidas enviar allí según su propia política de privacidad. Los informes son públicos, así que no incluyas datos personales ni de pago.
