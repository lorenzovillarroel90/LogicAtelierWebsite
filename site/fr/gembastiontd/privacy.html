Confidentialité de Gem Bastion TD

Comment Gem Bastion TD traite les données de jeu, les pourboires facultatifs et les demandes d’assistance.

Collecte de données Ce que l’app conserve Pourboires facultatifs Ce site web Aide et assistance Politiques associées

Collecte de données

Gem Bastion TD ne collecte aucune donnée personnelle et ne vous suit pas. L’app ne comporte ni compte, ni publicité, ni outil d’analyse.

Ce que l’app conserve

L’app conserve votre expédition et vos réglages sur votre appareil. Supprimer l’app efface ces données locales de l’appareil. Les sauvegardes de l’appareil se gèrent dans les réglages de l’appareil et du compte Apple.

Pourboires facultatifs

Si vous versez un pourboire, Apple traite l’achat. L’app utilise StoreKit d’Apple pour confirmer la transaction et ne reçoit pas vos données de carte bancaire. Apple gère l’historique des achats et les demandes de remboursement.

Ce site web

Ce site web statique n’utilise ni compte, ni formulaire, ni cookie, ni outil d’analyse, ni publicité, ni script de suivi tiers. GitHub Pages peut recevoir les journaux ordinaires de requêtes selon ses propres règles. Le site n’utilise pas ces journaux pour vous identifier ou créer un profil.

Aide et assistance

Vous pouvez joindre le développeur via le lien de la page d’assistance. GitHub traite les informations que vous choisissez d’y envoyer conformément à sa propre politique de confidentialité. Les signalements sont publics. N’y indiquez aucune donnée personnelle ni information de paiement.
