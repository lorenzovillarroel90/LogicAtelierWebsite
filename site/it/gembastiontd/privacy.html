Privacy di Gem Bastion TD

Come Gem Bastion TD gestisce i dati di gioco, le mance facoltative e le richieste di assistenza.

Raccolta dei dati Cosa salva l’app Mance facoltative Questo sito web Aiuto e assistenza Politiche collegate

Raccolta dei dati

Gem Bastion TD non raccoglie dati personali e non effettua tracciamento. L’app non usa account, pubblicità o strumenti di analisi.

Cosa salva l’app

L’app salva la spedizione e le impostazioni sul dispositivo. Eliminando l’app rimuovi questi dati locali dal dispositivo. Puoi gestire i backup dalle impostazioni del dispositivo e del tuo account Apple.

Mance facoltative

Se lasci una mancia, Apple elabora l’acquisto. L’app usa StoreKit di Apple per confermare la transazione e non riceve i dati della tua carta di pagamento. Apple gestisce la cronologia degli acquisti e le richieste di rimborso.

Questo sito web

Questo sito web statico non usa account, moduli, cookie, analisi, pubblicità o script di tracciamento di terze parti. GitHub Pages può ricevere i normali log delle richieste secondo le proprie politiche. Il sito non usa questi log per identificarti o creare un profilo.

Aiuto e assistenza

Puoi contattare lo sviluppatore tramite il link nella pagina di assistenza. GitHub tratta le informazioni che scegli di inviare in base alla propria informativa sulla privacy. Le segnalazioni sono pubbliche, quindi non includere dati personali o di pagamento.
